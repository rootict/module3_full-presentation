# 🛡️ Digital Safety & Email Etiquette - Interactive Module (03.4)

A fully interactive, animation-driven presentation module designed for ICT students. This web-based learning tool visually demonstrates real-world digital communication scenarios—ranging from phishing attacks and email routing to malware detection—using step-by-step, state-based animations.

Designed for seamless display on anything from 86" Smart Boards to mobile devices.

## ✨ Key Features & Animations

* **Anatomy of a Phishing Attack:** Step-by-step breakdown of a malicious email, featuring a hover-to-inspect UI that reveals hidden unsecure IP addresses.
* **Professional Email Etiquette:** Interactive mockup highlighting the essential components of a formal business email.
* **Reply vs. Reply All:** Visual data packet routing demonstrating the impact of broadcast replies on a team's inbox.
* **To, CC, & BCC Routing:** Real-time privacy simulation showing who sees what.
* **The Privacy Breach (Mass BCC Ethics):** A high-impact animation demonstrating how putting 500 clients in the "To" field exposes data, and how the "BCC Shield" protects identities.
* **Attachment Handling:** Compares the transmission of small direct files (under 25MB) versus routing large files via Cloud Drive links.
* **Malware & Anti-Virus Integration:** Radar scanning animations for quarantined `.zip` files and the immediate interception of dangerous `.exe` payloads.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure for presentation slides and interactive mockups.
* **CSS3:** Advanced keyframe animations, scalable variables (`var()`), dynamic SVG path dashing, and fully responsive media queries.
* **Vanilla JavaScript:** Custom state-machine logic to handle sequential step-by-step slide progression and DOM manipulation. No external libraries required.
